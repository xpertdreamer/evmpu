## Notes

The microprocessor emulator is a Windows application and is launched using Wine:

```bash
LC_ALL=ru_RU.UTF-8 wine ~/MT1804R2ProNew2.exe
```

The ``LC_ALL=ru_RU.UTF-8`` environment variable ensures correct display of Cyrillic characters in the interface. Make sure **Wine** is installed on your system before running this command.

Also, Visio "cross-system" and DOSBOX are running inside a VM (using libvirt in my case).
